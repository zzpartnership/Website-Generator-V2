# Accessibility notes — advisory

Checklist, not a gate. The reduced-motion path is a composed alternative, not motion switched off.

| Item | Page(s) | Status | Note |
|---|---|---|---|
| Body text contrast 4.5:1 against its ground; large type 3:1 | | | |
| Every interactive element reachable by keyboard in a sensible order | | | |
| Visible focus state on every interactive element, designed, not the browser default | | | |
| Every image has alt text or `alt=""` when decorative | | | |
| `prefers-reduced-motion` produces a composed static page: nothing hidden, nothing waiting | | | |
| Form fields have labels; errors are announced and described | | | |
| Landmarks: one `<main>`, `<nav>`, `<footer>`; skip link present | | | |
| Text can be zoomed to 200% without loss | | | |
| Video and autoplay media have controls or are muted and decorative | | | |
| Colour is never the only carrier of meaning | | | |
| Touch targets at least 44px on coarse pointers | | | |

Skill: `design:accessibility-review`.
