# Generative constraint pool

The Art Director draws from this for levels 5 and 6. `/pack` records which constraint went to which variant in `pack/plan.md`. A constraint is a rule the whole page obeys, visibly. It is where the variance comes from; do not soften it in execution.

| Constraint | What it forces |
|---|---|
| No rectangles | Every container, image and button is a non-rectangular shape. Clip paths, masks, arches, blades. |
| Two colours only | Exactly two tokens on the whole page. Tints of them are not allowed. |
| Type as image | The largest element on every screen is type. Photos are secondary or absent. |
| No photography | Colour, type, shape and texture only. AI-generated abstract allowed. |
| Everything off-centre | No element's horizontal centre sits within 10% of the page's centre. |
| One continuous scroll | No section boundaries. The page is a single composition that changes as you scroll. |
| No horizontal rules | Separation by space, colour and shape only. Not one `<hr>`, not one border-bottom. |
| Asymmetric everywhere | No two elements share an edge alignment on the same screen. |
| Full-bleed only | Nothing inside a max-width container. Every element touches at least one viewport edge. |
| Text over image never | Type and imagery never overlap. They share screens by division only. |
| Single typeface | One family. Contrast by size, weight and width alone. |
| No drop shadows | Depth by overlap, colour and scale only. |
| Diagonal composition | The primary axis of every screen is a diagonal. Type, images and shapes follow it. |
| Overlap required | On every screen at least two elements overlap. |
| Negative space dominant | At least 60% of every screen is empty ground. |
| Monochrome plus one | A single hue's tints and shades, plus one accent used at most three times on the page. |
| All-caps display only | Every heading is uppercase. Body is not. |
| No rounded corners | Not one border-radius on the page. |
| Edge-to-edge type | The hero heading touches both viewport edges. Break it across lines however needed. |
| Vertical text somewhere | At least one piece of running text is rotated 90 degrees and is read that way. |
| Grid of one | A single column at every width. Rhythm by scale and space alone. |
| Hard shadows only | Any shadow is a solid offset shape in a token colour, never blurred. |
| Nothing fades | Opacity is never animated. Everything enters by movement, clip or scale. |
| One motion only | A single primitive is used on the page, at most three times. |
| Print margins | Fixed margins, a visible baseline grid, and the page composed like a spread. |
| Half and half | Every screen is split in two along one axis; the split moves from screen to screen. |
